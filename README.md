# 대한민국 자동차 주행거리 분석

2012–2025년 자동차 주행거리 통계와 자동차 표시연비, 지역별 휘발유·경유·LPG 평균가격을 한 화면에서 확인하는 정적 웹 페이지입니다.

## 실행

`index.html`을 브라우저에서 열면 됩니다. 외부 서버는 필요하지 않습니다. 수식 렌더링에는 MathJax CDN을 사용하므로 인터넷 연결이 있으면 수식이 보기 좋게 표시됩니다.

## 파일 구성

- `index.html`: 분석 화면의 구조
- `style.css`: 페이지 스타일
- `app.js`: 필터, 표, 차트 및 분석 계산
- `data.js`: `D`(주행거리 통계)와 `FUEL_DATA`(연비·연료가격) 데이터
- `convert.js`: 같은 폴더의 원본 CSV/XLSX로 `data.js`를 다시 생성

## 데이터 다시 만들기

Node.js가 필요합니다. XLSX를 읽기 위해 `xlsx` 패키지를 설치하고 변환기를 실행합니다.

```sh
npm install xlsx
node convert.js
```

명령은 프로젝트 폴더에서 실행합니다. `convert.js`는 `426_*.csv` 주행거리 파일, 휘발유·경유·LPG 지역 가격 CSV, `자동차표시연비 목록.xlsx`를 찾아 `data.js`를 덮어씁니다. XLSX의 첫 워크시트에서 `출시연도`, `자동차 종류`, `연료`, `표시연비` 열을 읽습니다. CSV는 UTF-8 또는 EUC-KR 인코딩을 처리합니다.

`convert.js`는 주행거리 값의 원 단위(㎞)와 연간 거리 지표의 천 ㎞ 단위를 구분해 `app.js`가 사용하는 행 구조로 변환합니다. `data.js`를 생성하면 기존 파일 내용을 덮어쓰므로, 변환 후 앱을 새로고침해 변경된 데이터를 확인하세요.
